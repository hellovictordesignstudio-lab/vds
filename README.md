# VDS — Victor Design System

An open-source design system with React components, design tokens, and Figma resources.

## Packages

| Package | Description |
|---------|-------------|
| `@vds/tokens` | Design tokens in DTCG format |
| `@vds/react` | React components |

## Getting Started
```bash
npm install @vds/react
```

## Development
```bash
pnpm install
pnpm dev
```
